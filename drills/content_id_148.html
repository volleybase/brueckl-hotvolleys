Thema

Die Annahme im Oberen Zuspiel lernen.

Beschreibung

  1. Die Spielerin am Netz spielt eine leichten Schlag auf Kopfhöhe.
  2. Die Spielerin im Hinterfeld soll mit Oberen Zuspiel annehmen.
  3. Langsam die Entfernung erhöhen (1-3).
  4. Den Abschluss bildet die Position, an der die Annahme im Spiel erfolgt (4).

Hinweise

  • Die Annahmespielerin so anspielen, dass sie im oberen Zuspiel annehmen muss!
  • Bald zum Service über das Netz weitergehen - sonst ist es mehr eine Verteidigungsübung - nicht falsch, aber was Anderes.

Variationen

  • Wurf/Service über das Netz.

Bälle/Geräte

1 Ball pro Paar.
